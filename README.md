# Baobab CMS — core

Le cœur de Baobab CMS : un CMS modulaire et orienté développeurs, construit sur Laravel. Chaque Content Type possède sa vraie table typée (préfixe `ct_`), jamais d'EAV. Hooks, thèmes, API REST et GraphQL.

Ce paquet est le cœur du produit. Il s'installe normalement avec le squelette :

```bash
composer create-project baobab/baobab monsite
```
